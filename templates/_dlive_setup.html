Use the MixRack network address (for example DM32), not an audio, gigaACE or ME port. Surface S5000 network access is possible; verify the endpoint and firmware before enabling.

Mapping is manual: confirm each AUX's mono/stereo ordinal against the show. dLive uses different AUX IDs from DiGiCo; review group grants before allowing performers access. Saving or reading names never changes audio.

MixRack plain TCP: 51325. V2.0+ Surface plain TCP: 51328. TLS ports 51327/51329 and profile authentication are not supported: do not disable site security to use this provider. Use only an approved isolated control network. Enable MIDI Send and Receive in Utility / Control / MIDI.

AUX mappings

Mono AUX IDs are 1000 + bus; stereo AUX IDs are 2000 + bus. These are mono/stereo AUX ordinals, not physical output sockets or fader-strip positions.

Input mappings

Add only inputs performers may mix. Section headings retain the existing Personal Mix group tabs.

Send levels and read-only desk names are supported. Per-send mute, pan, metering and ME-1 remote control are unavailable; no whole-input mute is substituted. AUX master level/mute are available through the scoped API only, keeping the performer layout unchanged.
