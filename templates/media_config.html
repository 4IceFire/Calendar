Available media players

Choose the players available for displaying images and reserve their still slots for TDeck. Each player needs at least two still slots so a new image can upload before the player switches to it.

Set each VideoHub input to the feed that already carries that media player. Keep this feed set up manually on the ATEM. TDeck loads the image into an available player, then routes its VideoHub input to the selected screen.

Any other feeds already using that media player will show its new image too.

Switcher capabilities will appear when connected.
