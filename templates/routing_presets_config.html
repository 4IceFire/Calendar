Presets

Give each group access under Permissions → Groups → Routing. New presets are available to Admin until assigned to other groups.

New preset

Upload images in Config → Media.

Leave this as “Ask the user to choose” for the normal Routing output picker. Fixed outputs still require the user's output and media-input permissions.

Presets use the output's current media player, or reuse one already feeding other screens. All screens on that player receive the new image. If several players are eligible, their order in Config → Media breaks the tie.

Extra API actions (optional)

Actions run once, in order, after the image is confirmed on screen. If one fails, later actions stop. Completed actions are not undone. An API response may mean a device command was accepted and is still completing.

Use the same method, /api/ path and JSON body as scheduler API actions. TDeck authenticates the saved actions internally; no API token is needed. Operators may run these approved actions even without direct control access. Account, configuration and browser-only APIs cannot be used here.
